# 登录、退出、重置

用户要登录，或网页通话 / 外呼返回「需要登录 / 需要重新授权」时，走这里。登录用当前默认企业。不要跟「给别人手机号打体验电话」混在一起。

对用户只讲：手机号、验证码、协议链接、登没登上。不要念错误码、设备码、验证页、Token。

## 登录

1. 问手机号。
2. 展示协议（登录前必须出示，继续即同意）：
   - 隐私协议：https://work.whobot.com/legal/privacy
   - 用户协议：https://work.whobot.com/legal/terms
3. 用户说继续之后，再发验证码：

```bash
whobot auth login --phone <phone> --json
```

成功只表示短信已发出，**还没登录上**。记住 `data.verificationId`（`dvs_` 开头）。

4. 告诉用户：验证码已发到该手机；请把短信里的 6 位数字发给我。
5. 用户给了数字后：

```bash
stdin | whobot auth verify <verificationId> --code-stdin --json
```

验证码只能从 stdin 进，不要写在命令参数里。登录验证码不要和体验外呼验证码混用。

6. `data.status` 为 `authorized` 后立刻查一次状态，再用状态结果告诉用户登上了没有：

```bash
whobot auth status --json
```

只展示是否已登录、脱敏手机号。

## 登录没成功时

对用户说话，不要念 code。

| 情况 | 对用户说 | 接下来 |
| --- | --- | --- |
| 验证码不对 | 验证码不对 | 等用户再给，不要自己连打 |
| 验证码过期 | 验证码过期了，要重新发 | 再走一遍协议确认后重新 `auth login` |
| 登录没保存住 | 登录没保存成功 | 不要说已经登上 |
| 需要重置 | 需要先重置这台设备上的账号，再登录 | 确认后 `identity reset`，不要换号硬登。凭据损坏或刷新中断由 CLI 自动恢复，之后按未登录走上面的登录 |
| 企业变了 | 登录环境变了，需要重置后再授权 | 同上 |
| 暂时失败 | 登录暂时没完成，请稍后再试 | 停，不要自动重试 |

网页通话缺授权时：走上面的登录，不要改成匿名网页通话，也不要改成打电话。

## 退出和重置

三件不是一回事，命令前分别说明后果并得到确认。

**退出登录**（`whobot auth logout --json`）  
退出当前登录。公开列表还能看；再体验网页通话要重新登录。

**重置这台设备上的账号**（`whobot identity reset --json`）  
解绑并撤销这台设备上的登录。远端撤销成功后才清本地。结果不明时不要改成只删本地。

**只删本机记录**（`whobot identity forget-local --json`）  
只丢掉这台电脑上的登录文件。服务器上的登录可能还在。不能拿它代替重置。
